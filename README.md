
# Paletto: Swatch and Palette Designer

**The Ultimate 30-Tone Color Architecture Generator**

## Introduction
**Paletto** is a specialized web-based design tool built for creators who need more than just a simple "five-color" palette. Unlike standard generators, Paletto focuses on creating **comprehensive, 30-colour cohesive swatches**. Whether you are building a complex UI, a brand identity, or digital art, Paletto provides the depth and range necessary for a truly professional color system.

## 🎨 Why 30 Colours?
Most color tools provide a base set that leaves you guessing when you need hover states, disabled button colors, or subtle background variations. Paletto generates a massive, interconnected set of 30 tones that ensure:
*   **Visual Consistency:** Every shade is mathematically and aesthetically linked.
*   **UI Depth:** Plenty of options for shadows, highlights, and mid-tones.
*   **Scalability:** Enough variety to support dark mode and light mode themes simultaneously.

---

## 🚀 Key Features

### 💻 Live UI Preview Mode
Stop guessing how your hex codes will look in the real world. Paletto features a **Live Demo UI** that applies your current palette to a dummy application interface. 
*   See your primary colors on buttons and headers.
*   Test your neutral tones on backgrounds and borders.
*   Instantly identify if your contrast ratios work before you touch a line of code.

### 🛠 Versatile Export Options
Paletto makes the transition from "design" to "development" seamless with two main export formats:
*   **CSS Variables:** Generates a `:root` block with all 30 colors mapped to CSS variables—perfect for modern web development.
*   **JSON Objects:** Provides a structured data format for easy parsing into JavaScript, Python, or mobile app configurations.

### 🎯 Design & Refine
*   **Precision Control:** Adjust base hues and watch the entire 30-tone system update in real-time.
*   **Cohesive Swatching:** Ensure that your "vibrant" colors and "muted" tones share the same underlying DNA.

---

## 🛠 How to Use Paletto

1.  **Generate:** Start with a base seed color or explore random cohesive sets.
2.  **Preview:** Toggle the **Live UI** mode to see the palette in action on a mock dashboard.
3.  **Adjust:** Tweak individual tones until the balance is perfect.
4.  **Export:** Copy the CSS code directly into your stylesheet or download the JSON for your project.

---

## 📂 Developer Integration
If you are using Paletto for a web project, your exported CSS will look like this:
```css
:root {
  /* Paletto 30-Tone Suite */
  --primary-100: #e3f2fd;
  --primary-500: #2196f3;
  --primary-900: #0d47a1;
  /* ... and 27 more perfectly matched variables */
}
```
